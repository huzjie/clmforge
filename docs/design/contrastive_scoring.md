# 对比式打分设计

## 打分头

三种打分头，`scoring.py` 提供：

| 类型 | 公式 | 参数 |
|---|---|---|
| linear | `w·(e_s ⊙ e_a)` | O(d) |
| bilinear | `e_s^T W e_a` | O(d²) |
| mlp | `MLP([e_s; e_a])` | O(d·h) |

## 为什么对比而非生成

生成式决策把「选择」编码成「生成 token」，信息瓶颈在于自回归解码；对比式直接学习
一个打分函数，输出一个标量，天然并行、天然可缓存。

## 置信度 margin

```
margin = (top1 - top2) / (top1 - min)
```

margin ∈ [0,1]，是路由的核心信号。
