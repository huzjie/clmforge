# 常见问题

**Q: 必须装 GPU / PyTorch 吗？**
A: 不需要。核心是零依赖纯标准库；只有 `transformers` 后端需要 torch。

**Q: 为什么用 MD5 派生嵌入？**
A: 作为「冻结主干」的确定性零依赖替身，保证跨平台、跨运行可复现；接真实 encoder 只需覆写 `encode`。

**Q: 加速比为什么不是恒定的 9×？**
A: 取决于动作集合复用度。命中率高时加速大；动作每次全换时加速趋近 1×。

**Q: 能用于开放式生成吗？**
A: 不适合。开放式任务请走慢路径（生成式后端）。

**Q: 配置文件加载失败？**
A: 支持 YAML 子集与 JSON；内置 `yamlish` 解析器兜底，无需 `pyyaml`。
