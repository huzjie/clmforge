# 模块：core

- `config.py` — `CLMConfig` 与 `load_config`（YAML/JSON，内置 YAML 回退）
- `types.py` — `Action` / `Decision` / `ScoreResult` / `DecisionResult`
- `embeddings.py` — 确定性哈希嵌入 + 向量运算
- `scoring.py` — 三种打分头
- `hashutil.py` — MD5 确定性派生
- `registry.py` — 通用注册表
- `constants.py` / `exceptions.py` — 常量与异常
